# Licensed starter media

The repository owner has confirmed permission to copy the selected card scans and videos from the Duel Masters Card Database for this project.

## Sources

- Card scans: `https://img.duelmasters.us/{media-id}.webp`
- Card videos: `https://media.duelmasters.us/{media-id}.mp4`
- Database project: `https://github.com/bmenneni/SimpleJavaDmdb`

The import workflow converts the 41 starter-deck scans to PNG for Unity compatibility. Nine mapped creature videos remain MP4 files and are stored with Git LFS. These media permissions are distinct from the software licenses used by this repository.

## Imported scope

- All unique cards in Shobu's Fire Deck and Kokujo's Darkness Deck: 41 scans.
- Creature animations currently present in those decks: media IDs `0056`, `0077`, `0080`, `0087`, `0090`, `0095`, `0155`, `0157`, and `0168`.
